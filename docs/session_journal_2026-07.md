## 1. 라이브 캔버스 구축 — `6bc1c0b`

- `/api/regenerate`가 캔버스+구역을 제약 스케치로 변환해 기존 결정론 파이프라인(workflow-run/revision-run) 실행.

## 2. 실도면 투입과 엔진 버그 3건 — `50ca14c`
8MB/56,029요소 실도면(A-801~802 지하층평면도)이 드러낸 버그:
1. path의 arc(A) 플래그를 좌표로 오독 → 정식 path 커맨드 파서로 교체
2. `r="0.5px"` 단위 접미사에 float 변환 실패 → 단위 허용 파싱 (`_attr_num`)
3. `delete_elements`가 없는 cid에서 중간 실패 → find-then-remove + skipped 보고
UI 기본기 3종 추가: 휠 줌(커서 중심)·팬(Space/Alt/휠클릭)·전체보기, 폴링이 사용자 viewBox를 리셋하지 않도록
사용자 소유 viewBox, 좁은 창에서 사이드바가 캔버스를 밀어내던 레이아웃 수정.

## 5. 스케치 인식 문제 해결 — `1f51ef1`
증상: "브라우저에서 그린 그림을 에이전트가 전혀 인식 못 한다".
원인: 다점 도구(폴리라인·곡선·구역)가 더블클릭/Enter 확정 없이는 조용히 버려짐 + 옛 탭이 죽은 서버/구버전 JS에
연결된 채 그리기 시도 + 세션이 8770/8772 두 서버로 갈라져 있던 혼선.
해결: ① 도구 전환·우클릭 시 자동 확정 ② 매 커밋마다 `✓ 추가됨` 로그 ③ `list_elements(drawn=true)` —
세션 스트로크(crab_drawn/crab_zones 레이어)만 조회하는 에이전트 인식 경로 ④ 서버 단일화(8770 하나만).

## 6. 에이전트 CAD 승격 — 10대 격차 일괄 개발 (2026-07-07)
부족 진단 10건을 모두 구현:
방 인식(`recognize_rooms`: 굵은벽 flood-fill + 문틈 모폴로지 클로징, m²/평 산출) ·
CAD 스트레치(`stretch_elements`: 박스 내 점만 이동→벽 연장) · 드래프트-커밋(`draft`) ·
렌더 뷰(`render_view`: rsvg→cairosvg→qlmanage 폴백, MCP image 콘텐츠) ·
스케일 일급화(`set_scale`: 직접/캘리브레이션, 문서 속성 영속) ·
불가침 강제(no_go/lock 존이 draw/move/stretch 자동 차단, force 예외) ·
gzip 전송(8MB→~1.5MB) · 자동저널(3초 스로틀, 재시작 복구) ·
브라우저 스냅(끝점>직교(Shift)>그리드, 토글) · `/crab-cad` 스킬(.claude/skills).
검증: 실도면에서 밀폐실 면적 정확(1인독서실 3.9평, 용역원실 7.1평), 오픈플랜은 연결성 그대로 병합(정상),
draft→stretch(6점)→rollback 왕복, PNG 렌더 200KB. 테스트 111개 통과.
주의: 기존 MCP 브리지 프로세스는 재시작해야 신규 툴 6종이 노출됨.

## 8. 양방향 소통 채널 (2026-07-07)
브라우저↔LLM 연동의 4대 공백을 해소:
① `browser_state` — 사용자의 현재 선택(요소 상세로 해석)·뷰포트·💬 메시지(선택 동봉, drain)를 에이전트가 조회.
   "이거 지워줘"의 '이거'가 처음으로 해석 가능해짐. ② 뷰포트 공유 — render_view(bbox=viewport)로 같은 화면 보기.
③ 💬 에이전트에게 버튼/Enter — 브라우저에서 에이전트로 메시지 큐. ④ `notify_user` — 에이전트가 브라우저에
토스트(🤖)+깜빡이는 포인터 마커로 '여기' 지시. 선택 보고는 즉시, 뷰포트는 250ms 스로틀(레이스 수정).
라이브 왕복 검증: 줌→선택→메시지→세션조회→알림→마커 표시 전 구간 PASS. 테스트 122개.
